# Submission

## Description (under 250 words)

**Pactum is a transferable reservation bond for fine dining.** A restaurant creates a bond for a specific reservation and shares its link. The guest opens it inside Nimiq Pay, reviews the amount and cancellation policy, and sends NIM directly to the restaurant. Pactum independently verifies the transaction and issues a short-lived wallet-bound reservation pass.

If plans change, the current guest signs a clear transfer instruction to another Nimiq address. The previous pass becomes invalid immediately. At arrival, approved staff scan the current pass, check the guest in, and apply the bond to the bill. Restaurant owners can authorize refunds to the original payer, cancel a reservation, or record a forfeiture; every action appears in an audit timeline.

Pactum uses Nimiq Pay for wallet identity, explicit transaction confirmation, signed transfer authorization, and real NIM payments. It complements existing booking tools rather than replacing them.

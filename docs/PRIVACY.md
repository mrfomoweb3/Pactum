# Privacy and retention

Pactum stores wallet addresses, restaurant profile names, reservation terms, transaction hashes, current pass ownership, and an audit history. This is required to verify payment, prevent duplicate use, and resolve the current reservation holder.

Pactum never requests or stores seed phrases or private keys. Public links do not expose guest identity, wallet history, staff lists, or internal notes. Financial hashes and integrity events are retained because deleting them would allow replay and duplicate-payment claims. Users may request deletion of non-financial profile data through the maintainer’s GitHub contact channel.
